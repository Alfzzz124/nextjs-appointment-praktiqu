Source for `landing-page/pamela-anggia-dewi-en.html` — an English rebuild of the
archived Elementor page `psikolog-pamela-anggia-dewi.html`.

Design: `docs/superpowers/specs/2026-08-26-pamela-landing-page-en-design.md`

## Build

```
node build.mjs      # writes ../../pamela-anggia-dewi-en.html
node verify.mjs     # acceptance checks against the built file
```

`build.mjs` fails if any asset in `assets/` is never referenced, if a `{{…}}` token
is left unreplaced, or if the output goes over 600 KB.

## Assets

`assets/*.webp` is generated by `extract.mjs`, which reads the archived 17 MB page.
That page is gitignored, so the WebP files are committed — otherwise a fresh clone
could not rebuild. Rerun `extract.mjs` only to change an asset.

Conversion goes through a canvas in headless Chrome: this machine has no cwebp and
no ImageMagick, and no passwordless sudo to install either.

`logo-brainspotting-id.webp` is **white**. The old page laid it on a white
background, where it was invisible; here it sits on a dark chip. The file itself is
correct and must not be recoloured.

## Headless Chrome on WSL

Playwright's Chromium ships without its shared-library dependencies, and this box has
no passwordless sudo. The libraries live in `~/.local/share/chromium-deps`, so every
script that drives a browser needs:

```
LD_LIBRARY_PATH=$HOME/.local/share/chromium-deps node extract.mjs
LD_LIBRARY_PATH=$HOME/.local/share/chromium-deps node verify.mjs
```

`build.mjs` is pure file I/O and does not need it.

To rebuild that folder without sudo:

```
cd "$(mktemp -d)"
apt-get download libnspr4 libnss3 libasound2 libatk1.0-0 libatk-bridge2.0-0 \
  libcups2 libdbus-1-3 libdrm2 libgbm1 libpango-1.0-0 libcairo2 libxkbcommon0 \
  libxcomposite1 libxdamage1 libxfixes3 libxrandr2 libatspi2.0-0 libxshmfence1 \
  libexpat1 libxext6 libx11-6 libxcb1 libxau6 libxdmcp6
for f in *.deb; do dpkg-deb -x "$f" r; done
mkdir -p ~/.local/share/chromium-deps
cp -r r/usr/lib/x86_64-linux-gnu/* r/lib/x86_64-linux-gnu/* ~/.local/share/chromium-deps/
```

On a machine with sudo, `npx playwright install-deps chromium` does the same thing.
